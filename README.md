 Git Branching and Pull Request Workflow

## Project Overview

This project demonstrates the Git branching and Pull Request workflow used in collaborative software development.

## What I Did

* Created a new GitHub repository.
* Cloned the repository to the local machine.
* Created a new feature branch.
* Added and modified project files.
* Committed changes using Git.
* Pushed the feature branch to GitHub.
* Created a Pull Request (PR).
* Reviewed and merged the Pull Request into the main branch.

## Tools Used

* Git
* GitHub
* Linux (WSL)

## Key Concepts Learned

* Branch Management
* Git Commit Workflow
* Push and Pull Operations
* Pull Requests (PR)
* Code Review Process
* Branch Merging

## Outcome

Successfully implemented a Git workflow using feature branches and Pull Requests, similar to real-world software development teams.
